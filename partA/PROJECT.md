# Mini Library — Номын сан удирдлагын систем

## Зорилго

Жижиг номын санд зориулсан вэб програм. Номын нөөц, гишүүд, зээлэлтийг хялбар удирдах боломж олгоно.

## Scope (Хамрах хүрээ)

### Хамрагдах зүйлс ✅
- Номын CRUD (нэмэх, үзэх, засах, устгах)
- Гишүүний бүртгэл ба удирдлага
- Зээлэлт — ном авах, буцаах, хугацаа хэтрэлт
- Хайлт — номын нэр, зохиогч, жанраар
- Статистик — нийт ном, зээллэгдсэн, хугацаа хэтэрсэн

### Хамрагдахгүй зүйлс ❌
- Онлайн төлбөр
- Email/SMS мэдэгдэл
- Олон салбар

## Feature жагсаалт

| # | Feature | Тайлбар |
|---|---------|----------|
| 1 | Book Management | Ном нэмэх, засах, устгах, хайх |
| 2 | Member Management | Гишүүн бүртгэх, профайл харах |
| 3 | Loan Tracking | Зээлэлт олгох, буцаалт бүртгэх |
| 4 | Search & Filter | Нэр, зохиогч, жанр, статусаар шүүх |
| 5 | Dashboard Stats | Нийт тоо, зээлэлт, хугацаа хэтрэлт |

## Техникийн мэдээлэл

- **Backend:** Node.js + Express
- **Database:** SQLite (via better-sqlite3)
- **Frontend:** HTML + Vanilla JS (Express-ийн static files)
- **Port:** 3000
