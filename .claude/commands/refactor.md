# /refactor — Паттернаар Refactor

Доорх кодыг дараах зарчмуудыг баримтлан refactor хий:

**Шалгах зүйлс:**
1. **Single Responsibility** — Нэг функц нэг зүйл хийнэ үү?
2. **DRY** — Давтагдсан логик байна уу?
3. **Magic numbers/strings** — Тоо/мөр-ийг constant болгох
4. **Early return** — Nested if-ийг guard clause-аар солих
5. **Function length** — 20+ мөртэй функцийг хуваах
6. **Error handling** — Consistent байна уу?
7. **Naming** — Нэр нь утгыг илэрхийлж байна уу?

Гаргах:
- Одоогийн кодын асуудал жагсаах
- Refactored хувилбар
- Өөрчлөлтийн тайлбар
